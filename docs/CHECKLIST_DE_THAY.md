# Checklist đồ án theo đề cuối kỳ

- [ ] Mô tả vấn đề nhà đầu tư, người dùng và giá trị giải pháp.
- [ ] Chứng minh SSI FastConnect là nguồn chính; tối thiểu 2 nhóm API hoặc 1 WebSocket lưu trữ.
- [ ] Ít nhất 3 trường tài chính, dữ liệu thời gian có ngày, xử lý thiếu/trùng/lỗi/mất kết nối.
- [ ] Sơ đồ API -> thu thập -> chuẩn hóa -> tài chính -> phân tích -> giao diện.
- [ ] Giao diện có ngày cập nhật/trạng thái kết nối, >=3 KPI, >=2 trực quan, lọc, phân tích, phương pháp và giới hạn.
- [ ] Ghi rõ giả định, công thức, ngưỡng, tránh look-ahead và tín hiệu MUA tự động sai.
- [ ] Test tái hiện và ảnh chụp bằng chứng 3 trang (không để lộ tài khoản/key).
- [ ] README, dependencies, .env.example, data_sample, docs, report.
- [ ] Báo cáo khuyến nghị 8–12 trang A4, đúng khung thầy (Mục 14).
- [ ] Không dùng API để đặt lệnh thật; không công bố dữ liệu SSI trái điều khoản.
- [ ] Nộp mã nguồn, link sản phẩm chạy được/ghi hình, báo cáo; tên file theo mẫu MSSV_HoTen.
